## 2. Реален доверителен интервал на ROI

`evaluation.roi_confidence_interval(eligible)` - нова функция, върху
СЪЩИЯ `roi_eligible` списък, който вече строи `roi()`/`profit`/`avg_odds`
в `summary()` (никакъв втори филтър). Печалба на залог: `market_odds - 1`
при `won`, `-1` при `lost`. Wald 95% интервал: `mean ± 1.96 * SE`,
`SE = sample_sd / sqrt(n)` (n-1 знаменател за извадковата дисперсия).

**Реални числа от живата база (01.09.2026), точно поисканите:**

| | |
|---|---|
| n (settled, публикувани, с реален коефициент) | 308 |
| Победи / загуби | 198 / 110 (64.3%) |
| Среден коефициент | 1.765 |
| Средна печалба на залог | +4.70% |
| Стандартно отклонение (извадково) | 0.9299 |
| Стандартна грешка на средното | 5.30 пр.п. |
| **95% доверителен интервал** | **[-5.69%, +15.08%]** |
| Съдържа нулата? | **ДА** |

Потвърдено с независим ръчен скрипт (същата формула, различен код път) -
`mean` от скрипта = 4.6980519..., буквално равно на `evaluation.roi()`'s
съществуващ резултат (4.6980519...) - двата пътя мерят едно и също число,
само интервалът е нов. `+4.7%` при n=308 е статистически неразличимо от 0
- в рамките на шума, точно както Дака подозираше.

## 3. Пренареден отчет на /prognozi

Трите метрики вече са: **345** (уредени, непроменено) → **"обещахме
63.3% · познахме 64.6%"** (калибрация, "познахме" зелено само защото

НЕУТРАЛЕН цвят (не зелено/червено, защото 95% интервалът съдържа нулата) с

поисканото ново подреждане - същата статистическа несигурност като ROI,
не добавяше независима информация).

## evaluation.py: нова функция, реюзваема навсякъде

`roi_confidence_interval()` е добавена в `evaluation.py` (не в
`web/prognozi.py`) и вече е част от `summary()`'s връщан речник
(`scorecard["roi_ci"]`) - достъпна автоматично за `/results` и всяка бъдеща
