# sportbg.bg — извлечени дизайн стойности (25.09.2026 → 01.09.2026)

Метод: изтеглени реално `https://sportbg.bg/` и двата CSS файла, които зарежда
(`/build/300.6c50d495e61c4a4cbd22.css`, `/build/app.bd46cfd6ba80fe5d01ab.css`,
build на Bootstrap 5.3 + Font Awesome + собствени класове), с `curl`. Не е гледана
документация — стойностите по-долу са извадени директно от реалния CSS/HTML
на сайта. Суровите файлове: `/tmp/.../scratchpad/sportbg/` (не са в git — временни).

Сайтът е тъмна тема, но НЕ през Bootstrap-ов `data-bs-theme="dark"` — фонът
`#000` е зададен през собствено `body{background-color:#000}` правило, което
надделява над Bootstrap-овите default променливи (`--bs-body-bg`, `--bs-primary`
и т.н. в CSS-а още стоят на default стойности, но не се виждат никъде на
екрана — не са релевантни за копиране).

## Шрифт

| Стойност | Откъде |
|---|---|
| Основен шрифт (текст и заглавия) | `Inter` | `<link href="https://fonts.googleapis.com/css?family=Inter:300,400,500,700&display=swap&subset=cyrillic-ext">` в `<head>` |
| Зареждани тежести | 300 (light), 400 (normal), 500 (medium), 700 (bold) | същия `<link>` |
| Fallback в реалния CSS | `Inter, serif` | `body{font-family:Inter,serif}` в app.css |
| Основен body текст | 1rem (16px), тегло 400, line-height 1.5 | `--bs-body-font-size/-weight/-line-height` (Bootstrap default, непроменени) |

**Шрифтът е свободен и лесно възпроизводим** — Google Fonts, ясно указан
subset (`cyrillic-ext`, важно за кирилица), само трябва същия `<link>` таг.
**Забележка:** реалният fallback на сайта е `serif`, което е вероятно
неволна грешка от тяхна страна (при провален Google Fonts би паднало
рязко на serif вместо sans-serif) — **не копираме тази грешка**, в нашето
приложение fallback-ът остава системен sans-serif стек.

## Отстояния (spacing)

Наблюдавани `gap`/`padding` стойности, стъпка ~ кратни на 2px, без
единна scale-променлива в техния CSS: 4, 5, 6, 10, 12, 16, 20, 24, 26, 30, 50px.
Най-чести: **10px / 16px / 20px** — това е практическата "стъпка" в интерфейса им.

## Размери на шрифта по нива

Тук сайтът няма чист скейл — заглавията имат различни стойности в различни
контексти (responsive breakpoint-и, различни компоненти), пример:

| Елемент | Наблюдавана стойност |
|---|---|
| h1 (различни контексти) | 26px/32px, 28px/36px, или Bootstrap fluid `calc(1.375rem + 1.5vw)` |
| h3 (компонент/статия) | 30px/48px, тегло 800 — вероятно заглавие на статия |
| h3 (друг контекст) | 20px/26px или 24px/32px |
| `.modal-title` | 16px, тегло 600 |
| nav линк | 0.9rem (14.4px) |
| search резултат | 14px |

**Извод:** sportbg.bg няма строга типографска стълба (различни компоненти
имат различни ad-hoc размери) — не се опитваме да копираме несъществуваща
система, а само шрифта/тежестите/цветовете, които са консистентни навсякъде.

## Search (търсачка в header)

- `background-color:#000`, `border: 2px solid transparent`, `border-radius: 30px`,
  икона на лупа като фонова снимка отляво (`background-image:url(...search.svg)`),
  `color:#fff`, `font-weight:700`, свит на `width:200px`.
- При hover: `border-color:#727272`.
- При focus: `background-color:#232323`, `border-color:#1fae8c` (зеленият
  акцент), разширява се до `width:300px`.
- **Не е намерена еквивалентна "чипове за филтри" секция на началната
  страница** — sportbg.bg е новинарски портал, не таблица с мачове/пазари,
  затова няма пряк аналог на нашите филтър-чипове там. Най-близкото реално
  UI, което прилича на чип/таб (активен/неактивен), е табовете в модала за
  търсене (`.tabs .tab` / `.tab-active`): неактивен текст `#a0a0a0`, активен
  текст `#f7f7f7` (почти бяло). **Внимание:** буквалните CSS правила за
  hover/active border на тези табове сочат `blue` / `#add8e6` (светлосиньо)
  — това очевидно е неизползван/несъгласуван legacy код от споделена
  библиотека (никъде другаде на сайта не се вижда синьо), затова **не се
  копира**; за "активно" състояние следваме реалния зелен акцент (`#1fae8c`),
  който е консистентен на 3+ независими места (nav, search focus, .accented).

## Какво НЕ може да се копира 1:1

- **Логото** (SVG, чужда марка) — не се използва, само визуалния похват
  (sticky тъмен header) е референция.
- **Точната типографска стълба** — не съществува като единна система на
  техния сайт (виж по-горе), затова не претендираме за "sportbg скейл", а
  просто пренасяме шрифта/тежестите/цветовете в нашата вече съществуваща
  скромна скала.
- Font Awesome/Swiper/CKEditor CSS променливите, намерени в билда — не са
  тяхна марка, а vendor библиотеки, без значение за визията.
